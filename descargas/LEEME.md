# Descargar Sintaxia (Android)

Escaneá el QR (`qr-sintaxia.png`) o abrí este enlace desde el celular:

https://github.com/LeandroPereyra-arg/Sintaxia/raw/main/descargas/Sintaxia.apk

1. Se descarga `Sintaxia.apk`. Abrilo.
2. Si Android pregunta, permití **"Instalar apps de origen desconocido"** para el navegador.
3. Tocá **Instalar** y después **Abrir**.

Es la versión de ensayo (debug) conectada al proyecto de Supabase de la expo. Para
generarla de nuevo: `npm run android:debug` y copiar
`android/app/build/outputs/apk/debug/app-debug.apk` acá (ver `docs/20-apk-android.md`).
